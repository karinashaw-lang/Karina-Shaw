## Why this document

Second and final processed item of wave 127 (During employment slot,
2×2 pattern). The agent ruled out eleven candidates via specific
section-number greps before landing here — personnel/payroll records
inspection (Lab. Code §1198.5), the polygraph prohibition (Lab. Code

on §5193 in any form before drafting, and it fits alongside the
corpus's existing sibling Cal/OSHA "During employment" documents
(Hazard Communication §5194, Heat Illness §3395/3396, Noise Exposure).

## Genuine findings

- **A disclosed, deliberate scoping choice consistent with the house
  style**: each authority clause's gap field names, with specificity,
  exactly which adjacent subsections of the same statutory provision
  were deliberately not reproduced (e.g., the full eight-item
  Exposure-Control-Plan element list, the glove/mask/respirator-
  specific PPE rules, the Appendix A mandatory declination statement,
  the confidentiality restrictions on medical-record disclosure) —
  consistent, disclosed scope limitations rather than silent omission.
- **A disclosed choice not to independently cite the standard's own
  enabling-authority statutes**: the regulation's own text notes its
  basis in Lab. Code §§142.3 and 144.7, but the agent did not
  independently fetch or verify those as separate statutory sources,
  and disclosed that choice rather than citing them secondhand.
- **A disclosed, deliberate choice not to cite unverified case law**:
  CourtListener's daily quota was exhausted on the agent's test call;
  every authority clause proceeds on regulatory text alone.
- **Zero formatting artifacts required disclosure**: unlike several
  other documents this project has produced, all 20 citation quotes
  from this DIR-hosted HTML source matched cleanly on direct
  normalized-whitespace substring check with no ellipsis, stitching,
  or extraction-artifact issues.

## Honest gap(s) disclosed

This document does not reproduce the regulation's full eight-item
Exposure Control Plan element list, its fourteen-item required
training-content list, the full definition of "Other Potentially
Infectious Materials" or the regulation's many other defined terms,
the detailed procedure-specific requirements for needleless systems
and prohibited practices, the glove/mask/eye-protection/respirator-
specific PPE rules, the Appendix A mandatory vaccination-declination
statement, the detailed consent-and-testing sequence for post-exposure
evaluation, the confidentiality limits on a healthcare professional's
written opinion, the three-year training-record and five-year
Sharps-Injury-Log retention periods, employee access rights to medical
records, or the transfer-of-records obligations when an employer
ceases doing business. It does not itself constitute an employer's
written Exposure Control Plan and says so explicitly, consistent with
"inform, never advise."
