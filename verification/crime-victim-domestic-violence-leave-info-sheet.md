# During employment, new document: Crime Victim and Domestic Violence Leave — Information Sheet

## Why this document

This topic was previously only a brief cross-reference inside an
existing clause, `juryduty_related_but_distinct_scope`, in the corpus's
existing Jury Duty and Witness Leave document — which itself explicitly
declined to verify the current status of former Labor Code § 230.1. This
document closes that exact gap and substantially deepens coverage: notice
and certification, confidentiality, and reasonable accommodation, none of
which the existing passing mention addressed. Fourth and final document
of wave 54, closing the "1×4" pattern.

## What this document covers

8 clauses: 2 drafting (declaration, acknowledgment) and 6 authority
clauses, citing former Cal. Lab. Code §§ 230 and 230.1 alongside their
current codification at Cal. Gov. Code § 12945.8:

- **`dvleave_codification_status`** — **the central finding**: former
  Labor Code §§ 230 and 230.1 now carry sunset language limiting them to
  conduct occurring on or before December 31, 2024, with repeal scheduled
  for January 1, 2035; the same protection was relocated, effective
  January 1, 2025, into Government Code § 12945.8 under FEHA (most
  recently amended by AB 406, effective October 1, 2025).
- **`dvleave_core_protected_reasons`** (Gov. Code § 12945.8(a)(3)-(4),
  historical Lab. Code § 230(c)) — victim relief-leave protection, plus a
  new judicial-proceeding leave right commencing January 1, 2026.
- **`dvleave_25plus_expanded_purposes`** (Gov. Code § 12945.8(b), (i);
  historical Lab. Code § 230.1(a)) — a real, text-confirmed expansion:
  the historical 25-employee-threshold provision covered 4 purposes; the
  current one covers 10, plus statutory leave caps.
- **`dvleave_notice_certification`** (Gov. Code § 12945.8(c)(1)-(2);
  historical Lab. Code § 230(d)(2)) — advance notice and post-hoc
  certification for unscheduled absences.
- **`dvleave_confidentiality`** (Gov. Code § 12945.8(c)(3), (e)(7)(D);
  historical Lab. Code § 230(d)(3)) — confidentiality duties for both
  leave requests and accommodation documentation.
- **`dvleave_reasonable_accommodation`** (Gov. Code § 12945.8(e)(1)-(2),
  (f); historical Lab. Code § 230(f)(1)) — the reasonable-accommodation
  duty, confirmed to carry no employer-size threshold unlike the
  expanded leave-purpose provisions.

## Genuine corrections and findings

- **The central recodification finding**: independently fetched and
  confirmed that former Labor Code §§ 230 and 230.1 are now
  transitional-only statutes (capped at pre-2025 conduct, repealed
  2035), with the operative protection now at Government Code § 12945.8.
  This closes a gap the existing Jury Duty document explicitly declined
  to verify.
- **A real scope expansion, text-confirmed on both sides**: the
  historical 25-or-more-employee leave provision listed 4 purposes;
  the current Government Code provision lists 10.
- **A real asymmetry in employer-size thresholds**: the expanded
  leave-purpose list requires 25+ employees, but the reasonable-
  accommodation duty carries no employer-size threshold at all —
  confirmed by the statutory text having no such limiting language in
  subdivision (e)(1).
- **A new January 1, 2026 judicial-proceeding leave right** was found in
  current Gov. Code § 12945.8(a)(4), with no historical Labor Code
  counterpart — flagged with its own commencement date rather than
  treated as already effective.
- Confirmed a parallel confidentiality duty applies to both leave
  requests and separately to accommodation documentation, each with its
  own notice-before-disclosure requirement.

## Honest gap disclosed

The statute's "reasonable advance notice" and "not feasible" standards
are left undefined by its own text and not resolved here. The
"undue hardship" limit on the accommodation duty (cross-referenced to
Gov. Code § 12926 and Lab. Code § 6400) was not independently verified.
The accommodation-specific certification and six-month recertification
provisions in § 12945.8(e)(7) beyond the confidentiality subparagraph
were not restated. Secondary legislative-history commentary on AB 2499
and AB 406 was not independently verified — only the current statutory
text itself.
