# During employment, new document: Hazard Communication Standard — Information Sheet

## Why this document

First processed item of wave 122 (During employment slot, 1×4
pattern). The agent's first candidate, the right to discuss/disclose
wages (Lab. Code §§232/232.5), was found substantially overlapping in
underlying legal fact with the existing `fairpay_retaliation_and_wage_discussion_protection`
clause (which covers the same protection under Lab. Code
§1197.5(k)), so the agent pivoted away rather than risk a repeat of a
recent duplication finding in this same category. A consolidated
workplace-posting document was also considered and rejected as likely
to restate individual posting duties already scattered across existing
documents. The chosen topic — Cal/OSHA's Hazard Communication Standard
(8 Cal. Code Regs. §5194) — was confirmed genuinely open: zero corpus
hits for "5194," "hazard communication," "safety data sheet," "SDS," or
"GHS." Personally reconfirmed via corpus search: zero prior mentions of
"5194" or "safety data sheet" anywhere in the corpus, and confirmed the
existing Injury and Illness Prevention Program document (Lab. Code
§6401.7 / 8 CCR §3203) covers the general safety-program
administrator/hazard-evaluation scheme, not chemical-specific
labeling/SDS/training duties.
